# Сторонние компоненты и материалы

Раскрытие для HackAlem AI, §5.4.4 положения. Полные списки зависимостей и версии: `requirements.lock` и `frontend/pnpm-lock.yaml`; `requirements.txt` дублирует Python lock. LICENSE/NOTICE зависимостей сохраняются в установленных пакетах.

Основные backend-компоненты (метаданные установленных пакетов):

- FastAPI 0.128.8 — MIT.
- Uvicorn 0.39.0 — BSD-3-Clause.
- Pydantic 2.13.5 — MIT.
- python-docx 1.2.0 — MIT.
- PyMuPDF 1.26.5 — GNU AGPL 3.0 или коммерческая лицензия Artifex. Наличие коммерческой лицензии этим проектом не заявляется.
- openpyxl 3.1.5 — MIT.
- OpenAI Python SDK 2.48.0 — Apache-2.0.
- pytest 8.4.2 — MIT.

Frontend использует React, React DOM, TypeScript, Vite, Tailwind CSS, PostCSS, Autoprefixer и Lucide. Их LICENSE и сведения об авторах поставляются в npm-пакетах; эти компоненты не являются авторской разработкой команды.

SQLite используется через стандартную библиотеку Python. Опциональный AI обращается к внешней модели из `OPENAI_MODEL`; веса модели и API-ключи в репозиторий не входят. Для основного сценария модель не требуется.

OpenAI Codex использован для исследования проекта, написания и анализа кода, документации и тестирования. Это раскрытие инструмента разработки, а не независимая экспертная валидация.

Данные:

- Две редакции «Внутреннего аудита» предоставлены организатором; оригинальные DOCX локально вне Git. Контрольные цитаты и SHA-256 — в `truth/source_truth.json`.
- `examples/control` — синтетические тексты и DOCX для воспроизводимой проверки; не описывают Казахтелеком и не являются независимым отраслевым датасетом.
- `truth/source_truth.json` — авторская разметка при разработке, `human_signoff=null`.

Этот файл не перелицензирует сторонний код, модели или материалы организатора.
