# Контрольная разметка источников

`source_truth.json` содержит 22 вручную сверенных с текстом случая: пять организационных изменений, три сохранённые функции, четыре подтверждённых наблюдения (два переноса и два потенциальных риска), три неоднозначных случая и семь запрещённых утверждений.

У каждой записи есть цитаты обеих редакций, физические номера абзацев, ожидаемый тип и обоснование. Хэши фиксируют конкретные исходные файлы. `p0000` — первый абзац основной части DOCX; пустые абзацы учитываются при нумерации. Это не номер страницы Word.

«Подтверждённое наблюдение» о потенциальном риске подтверждает основание для проверки, а не потерю функции, нарушение или конфликт в реальной организации. Например, отсутствие прежнего явного права формировать группы контроля качества сопоставляется с сохранением самой функции качества и уполномоченных работников.

Разметка подготовлена при разработке по исходным абзацам. Независимого human signoff пока нет (`null`); его нельзя выдавать за состоявшуюся экспертную приёмку. Для приёмки аудитор сверяет каждую цитату, ожидаемый тип, контраргументы и ограничение, после чего добавляет отдельный подписанный журнал проверки, не меняя исходные цитаты.

Runtime не импортирует этот файл. Тесты сверяют SHA-256, все цитаты и ожидаемые типы. Запрещённые случаи проверяют сохранение ДНМ/ДККМ, отсутствие выдуманного исключительного владельца ДОА, невозможность восстановления пустого пункта и недопустимость превращать потенциальный конфликт в доказанное нарушение.

Синтетические adversarial-кейсы в `backend/tests/test_adversarial.py` независимы от демопары. Они не являются фактами о предоставленных документах.
